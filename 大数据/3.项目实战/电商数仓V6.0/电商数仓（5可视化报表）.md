## 第1章 Superset 入门

### 1.1 ⭐ Superset 概述

Apache Superset 是一个**开源的数据探索和可视化平台**，支持丰富的图表类型和交互式仪表盘。

**核心特性：**
- 🔥 **丰富的可视化**：折线图、柱状图、饼图、地图、热力图、漏斗图等 40+ 图表类型
- **SQL Lab**：在线 SQL 查询编辑器
- **仪表盘**：可拖拽布局的交互式 Dashboard
- **多数据源**：支持 MySQL、PostgreSQL、ClickHouse、Hive、Presto 等

### 1.2 📝 环境说明

| 组件 | 版本 |
|------|------|
| Python | 3.8 |
| Superset | 2.0.0 |
| 元数据库 | MySQL 8.0 |
| 数据源 | MySQL（ADS 层数据导出） |

## 第2章 Superset 安装

### 2.1 ⭐ Python 环境（Miniconda）

```bash
# 安装 Miniconda
bash Miniconda3-latest-Linux-x86_64.sh -b -p /opt/module/miniconda3

# 创建 Python 3.8 虚拟环境
conda create -n superset python=3.8 -y
conda activate superset
```

### 2.2 🔥 Superset 部署

```bash
# 安装依赖
pip install apache-superset==2.0.0 -i https://pypi.tuna.tsinghua.edu.cn/simple

# 安装 MySQL 驱动
pip install mysqlclient

# 配置 Superset 元数据库
# 编辑 superset_config.py
export SUPERSET_CONFIG_PATH=/opt/module/superset/superset_config.py
```

**superset_config.py：**

```python
# Superset 元数据库配置
SQLALCHEMY_DATABASE_URI = 'mysql://superset:superset123@hadoop102:3306/superset?charset=utf8'

# Secret Key
SECRET_KEY = 'your_secret_key_here'

# 允许嵌入
ENABLE_CORS = True
```

```bash
# 初始化数据库
superset db upgrade

# 创建管理员用户
superset fab create-admin \
    --username admin \
    --firstname Admin \
    --lastname User \
    --email admin@example.com \
    --password admin123

# 初始化角色和权限
superset init

# 启动开发服务器
superset run -h 0.0.0.0 -p 8787 --with-threads --reload --debugger
```

#### 🔥 Superset 启停脚本

```bash
#!/bin/bash
# superset.sh
case $1 in
"start")
    echo "========== 启动 Superset =========="
    conda activate superset
    gunicorn \
        -w 5 \
        -k gevent \
        --timeout 120 \
        -b 0.0.0.0:8787 \
        --limit-request-line 0 \
        --limit-request-field_size 0 \
        "superset.app:create_app()" \
        -D
;;
"stop")
    echo "========== 停止 Superset =========="
    ps -ef | grep superset | grep -v grep | awk '{print $2}' | xargs kill -9
;;
esac
```

## 第3章 Superset 使用

### 3.1 🔥 对接 MySQL 数据源

1. 登录 Superset → **Data** → **Databases** → **+ Database**
2. 选择 **MySQL**
3. 填写连接信息：
   ```
   mysql://root:000000@hadoop102:3306/gmall_report
   ```
4. 点击 **Test Connection** 验证连接
5. 保存

### 3.2 🔥 制作仪表盘

#### Step 1：创建数据集（Dataset）

- Data → Datasets → + Dataset
- 选择数据库 → 选择 Schema → 选择表
- 例如选择 `ads_user_retention`（用户留存率表）

#### Step 2：创建图表（Chart）

常用图表类型：

| 图表类型 | 适用场景 | ADS 层对应指标 |
|----------|---------|---------------|
| **折线图** | 趋势分析 | 🔥 DAU/MAU 趋势 |
| **柱状图** | 对比分析 | 各渠道流量对比 |
| **饼图** | 占比分析 | 各品类销售占比 |
| **地图** | 地域分析 | 🔥 各省份 GMV 分布 |
| **漏斗图** | 转化分析 | 🔥 浏览→加购→下单→支付 |
| **表格** | 明细展示 | 品牌复购率排名 |
| **数字卡片** | 核心指标 | 当日 GMV、新增用户数 |

#### Step 3：编辑仪表盘

- Dashboards → + Dashboard
- 拖拽图表到画布
- 调整布局和大小
- 添加筛选器（日期、渠道等）
- 保存并发布

## 第4章 Superset 实战

### 4.1 ⭐ 制作地图（各省份交易统计）

**数据源**：`ads_province_order`

**配置步骤**：
1. 新建 Chart → 选择 **China Map**
2. 设置维度：`province_name`
3. 设置指标：`SUM(order_total_amount)`
4. 颜色方案：连续色阶
5. 保存到仪表盘

### 4.2 ⭐ 制作漏斗图（用户行为转化）

**数据源**：自定义 SQL（SQL Lab）

```sql
SELECT '浏览' AS stage, COUNT(DISTINCT mid) AS user_count FROM dws_traffic_session_page_view_1d WHERE dt = '2024-01-20'
UNION ALL
SELECT '加购', COUNT(DISTINCT user_id) FROM dws_trade_user_cart_add_1d WHERE dt = '2024-01-20'
UNION ALL
SELECT '下单', COUNT(DISTINCT user_id) FROM dws_trade_user_order_1d WHERE dt = '2024-01-20'
UNION ALL
SELECT '支付', COUNT(DISTINCT user_id) FROM dws_trade_user_payment_1d WHERE dt = '2024-01-20';
```

### 4.3 📝 制作饼图（品类销售占比）

1. 新建 Chart → 选择 **Pie Chart**
2. 数据源：`ads_category_order`
3. 维度：`category_name`
4. 指标：`order_total_amount`
5. 显示比例标签

### Q2：数据可视化的流程？

1. ADS 层计算好指标
2. 通过 DataX 将指标**导出到 MySQL**
3. Superset **连接 MySQL** 数据源
4. 创建数据集 → 制作图表 → 编辑仪表盘
5. 通过 DolphinScheduler **定时刷新**数据
